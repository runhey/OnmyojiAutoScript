# 手机／其他设备登录礼让

当同一账号在手机或另一台设备登录，游戏会在当前客户端显示异地登录提示。
开启礼让后，脚本识别该提示便中断当前任务，暂停输入和游戏／模拟器启停，
到期由原有调度器派发一次 `Restart` 恢复登录，再继续原任务。

## 配置

在 OASX 为需要的配置打开“脚本 → 手机游玩礼让 → 启用”。默认关闭，
不依赖配置文件名；各配置分别保存自己的计时状态。

- `script.account_yield.enable`：是否启用，默认 `false`。
- `script.account_yield.pause_minutes`：礼让分钟数，默认 `20`，范围 `1–240`。
- 等待中修改时长会从最初检测时刻重算截止时间，不重新开始倒计时。
- 停止工作进程不会触发自动重登；手动重新启动后读取原来的截止时间。
- 关闭功能会解除输入保护；重新开启仍会读取保留的等待记录。

状态仅保存在 `log/account-yield/<配置名>/state.json`，不保存账号、密码或
截图。等待和恢复均使用现有工作进程，没有后台定时器替用户启动已停止的配置。
不会修改任务开关、下次执行时间、账号、设备或购买预算。

## 识别与恢复边界

当前识别器针对 OAS 的 `1280×720` 中文游戏截图，要求中央区域存在高置信度的
“账号在其他设备登录”消息和对应对话框按钮。普通网络断开、低置信度 OCR、
聊天栏或缺少按钮的文本不会触发。礼让异常绕过普通任务失败恢复，避免被自动重启顶掉手机会话。

同一个弹窗不会重复延长等待。到期派发一次恢复，随后连续两张截图确认实际庭院，
才重新允许识别下一次异地登录。持久化状态损坏时拒绝继续输入，留待排查。

离线测试可验证识别条件、计时、输入保护与调度；真实异地登录提示和完整重登仍需
在实际游戏中验证。尚未完成这项实机验收，不能用离线测试结果替代。
