# FrogBoss 对弈竞猜

十周年对弈竞猜（活动总览 → 对弈竞猜，左右红蓝双鼓押注）自动化。

## 流程（2026-10 重做）

1. 主页右侧活动栏进入竞猜页（`I_FROG_BOSS_ENTER`，2026-09-30 实测仍有效）
2. 状态机按画面分流：
   - **可下注（双"竞猜"鼓）**：OCR "剩余时间 MM:SS" 推算本轮结算时刻；距结算 >
     before_end（默认15分钟）→ 改期到"结算前15分钟"再来；已进入下注窗口 → OCR
     双方人数 → 按策略选边 → 点鼓 → 弹窗选档投入 → 点竞猜 → 确认 →
     下一轮下注时刻 = 本轮结算 + 2h - 15min
   - **竞猜成功（胜/败鼓 + 宝箱）**：点宝箱 → 关奖励结算 → 点"下一局"
   - **竞猜失败**：直接点"下一局"
   - **已竞猜（单鼓）**：按剩余时间推算下一轮下注时刻
   - **休息中**：8:30-23:59 窗口内 → 下一个偶数整点+5min 再看；窗外 → 明早 8:35
3. 最后一场（结算越过 23:59 窗口）下注完成后，下次运行定为明早 8:35，顺带收昨晚结果

## 大神策略

- 拉取博主（网易大神）最新动态，只认与本场同属一个 2 小时时段的帖子，
  按"押红/押蓝"关键词在文中出现位置投票，多数决；平票反压场上人数少的一边
- `frog_dashen`：跟随池内多数博主；`frog_dashen_specific`：只看 `dashen_uid`
  指定的博主，其本场没发帖自动回退跟随多数
- `dashen_pool` 自定义博主池：每行"昵称,uid"，留空用内置 26 人池。
  **uid 是大神博主主页网址 `ds.163.com/user/<uid>` 路径里那串 hex id**
- 请求均 5s 超时，拉取总预算 240s，循环内定期 `stuck_record_clear()` 保活

## 防重启设计（2026-09-30 教训）

旧版模板在十周年新 UI 上全部失配（整体缩放约 0.85），主循环 60 秒零点击触发
GameStuckError → 重启游戏 → 反复循环。现版本：

- 主循环每轮 `stuck_record_clear()`，卡死保护交给自己 150s 软超时兜底
  （无法识别 → 存截图 + 推送 + 30 分钟后重试）
- 下注两步（选档/确认）全部带 Timer 上限与验证；失败只推送+改期，绝不无限等
- 每轮结算时刻用 OCR 倒计时实推，不依赖固定场次表（自愈：估错场次下次到点会再校正）
