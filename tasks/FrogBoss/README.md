# FrogBoss 对弈竞猜

十周年对弈竞猜（活动总览 → 对弈竞猜，左右红蓝双鼓押注）自动化。

## 场次表（2026-10-01 用户确认）

- **首场 8:30 开、10:00 结算**；其余每场整点开、两小时后整点结算
  （10-12、12-14 … 20-22、22-24）
- 下注窗口为每场**结算前 15 分钟**（`before_end_frog` 可调）

## 流程

1. 主页右侧活动栏进入竞猜页（`I_FROG_BOSS_ENTER`）
2. 状态机按画面分流：
   - **可下注（双"竞猜"鼓）**：OCR "剩余时间 MM:SS" 推算本轮结算时刻；距结算 >
     before_end → 改期到"结算前15分钟+1min"再来；已进入窗口 → OCR 双方人数 →
     策略选边 → 点鼓进下注界面 → 按配置档位点 5 档之一（坐标点选，见下） →
     点右侧"竞猜"鼓 → "是否确认"弹窗点确定 → 校验已竞猜 →
     下一轮下注时刻 = 本轮结算 + 2h - before_end
   - **竞猜成功（胜/败鼓 + 宝箱）**：点宝箱（两种外观模板）→ 奖励结算页点
     "点击屏幕继续"（点不到就隔 2.5s 点宝箱原位置，避开奖励图标）→ 点"下一局"
   - **竞猜失败**：直接点"下一局"
   - **已竞猜（单鼓"已竞猜"）**：按剩余时间推算下一轮下注时刻
   - **休息中**：按场次表唤醒到下一场开场后 3 分钟
3. 最后一场（22-24）下注完成后，下次运行定为明早 8:33，顺带收昨晚结果

## 下注界面要点（图2/图8 素材实测）

- 点主页面竞猜鼓后进入**全屏下注界面**（不是小弹窗）：标题"竞猜"、右上角持有金币、
  底部 5 档礼盒（2万/5万/10万/20万/30万，中心 x=273/430/593/750/907, y=610）、
  右侧"竞猜"鼓按钮（模板 `fb_bet_go`，从弹窗压暗截图裁的，暗化不影响相关分）
- 点竞猜后弹"花费X万金币竞猜X方获胜，是否确认"，点金色"确定"
- **金币不足防护**：点了竞猜不出确认弹窗 = 该档投不起，自动降档重试直到最低档；
  全部失败则关闭界面（红叉）+ 推送通知 + 30 分钟后重试，绝不无限等待/重启

## 大神策略

- 拉取博主（网易大神）最新动态，只认与本场同属一个 2 小时时段的帖子，
  按"押红/押蓝"关键词在文中出现位置投票，多数决；平票反压场上人数少的一边
- `frog_dashen`：跟随池内多数博主；`frog_dashen_specific`：只看 `dashen_uid`
  指定的博主，其本场没发帖自动回退跟随多数
- **`dashen_pool` 博主池：界面里逐条"昵称,uid"（带新增按钮），已预填活动活跃的 21 人池；全部清空则回退代码内置池。
  **uid 是大神博主主页网址 `ds.163.com/user/<uid>` 路径里那串 hex id**
- 请求均 5s 超时，拉取总预算 240s，循环内定期 `stuck_record_clear()` 保活

## 防重启设计（2026-09-30 教训）

旧版模板在十周年新 UI 上全部失配（整体缩放约 0.85），主循环 60 秒零点击触发
GameStuckError → 重启游戏 → 反复循环。现版本：

- 主循环每轮 `stuck_record_clear()`，卡死保护交给自己 150s 软超时兜底
  （无法识别 → 存截图 + 推送 + 30 分钟后重试）
- 下注每一步（进界面/选档/竞猜/确认/校验）全部带 Timer 上限；失败只推送+改期
- 结算时刻用 OCR 倒计时实推，不硬编码依赖场次表（自愈：估错下次到点会再校正）
